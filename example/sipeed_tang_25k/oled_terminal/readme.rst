====================
 Pmod OLEDrgb text
====================

Displays a static 16x8 text screen on a Digilent Pmod OLEDrgb
(SSD1331) plugged on J4, using the DVI terminal text buffer and the
6x8 font.  Rows exercise the palette (red, green, blue lines), the
column ruler and corner markers make orientation and mirroring
obvious.  Done LED toggles every 32 frames as a refresh heartbeat.
